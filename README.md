# Inkmark

Annotate screenshots and photos in your browser: arrows, boxes, highlights and
text, then download or copy the result. Images never leave your device.

**Live:** https://inkmark.dev

## Run locally

```bash
npm install
npm run dev
```

Built with Vite and vanilla JavaScript. Icons by [Lucide](https://lucide.dev),
color picker by [vanilla-colorful](https://github.com/web-padawan/vanilla-colorful).
